Entry for the [news-image-20261124 bounty](https://make.fun/bounty/news-image-20261124) on make.fun.

This entry is a Python program that copies a pre-generated 1024x1024 newspaper front page summing up Tuesday 24 November 2026 world news — 35 dated stories across 7 regions, with a KPI strip, a region bar, three drawn lead stories (Huang's return sends Asian chips to records, Shanghai party chief Chen Jining probed, Zaporizhzhia hit as the war spreads), ten drawn secondary stories, a world map with numbered pins, a 22-item "also on" list, verification badges and a DATE CHECK box. The program itself uses only the Python standard library: it copies the image file the repository holds, so every run produces byte-identical output.

## Run

```sh
python3 main.py
```

The program writes `entry.png` (to `/output` when available, otherwise to `out/entry.png` next to `main.py`).
